## 交付

- APK：`artifacts/agentlink/AgentLink-1.3.0-android.apk`
- SHA256：`367dff43e4ea365ccfbae0eb305141a8910f5eb4c13b602a8b40aa46fff19dc2`
- 电脑入口：项目根目录 `启动局域网连接.command`
- 操作说明：[局域网连接指南](lan-host.md)

手机和电脑在同一局域网时，App 自动发现电脑。首次点击电脑后，核对手机与电脑管理页显示的 8 位数字，在电脑批准连接。之后从已保存电脑列表一键连接。电脑管理页支持单独撤销手机授权。保留扫码和手动连接入口。

新连接使用固定证书指纹的 TLS，不需要公网域名或公共 HTTPS 证书。UDP 广播只提供发现信息，不授予访问权限；配对通过承诺与揭示校验两端数字，设备令牌独立且可撤销。手机安全存储凭据，电脑持久化令牌哈希。旧 HTTP 配对码入口仍属独立授权途径，撤销某台设备不会使另行发放的旧配对码失效。

## 待用户真机验收

本轮本机 Android Emulator 可执行文件及原测试 AVD 已不存在，恢复模拟器组件时下载报 Connection reset，因此未完成 1.3.0 的模拟器安装验证，也未执行真机测试。先前版本的模拟器测试不计入本版本验收。

1. 安装上述 APK；电脑双击启动器，保持手机和电脑处于同一 Wi-Fi。
2. 手机点击发现的电脑，核对两端 8 位数字，在电脑批准；确认进入项目及会话。
3. 关闭再打开 App，从已保存电脑一键连接；分别检查 Codex、CodeBuddy 的项目、对话和已有审批流程。
4. 在电脑撤销手机授权，确认手机无法继续读取或控制会话；重新配对恢复。
5. 验证取消配对后电脑迟到批准不能使手机进入会话；验证扫码和手动入口仍可使用。

访客 Wi-Fi、AP 隔离、防火墙或 VPN 可能阻止发现及连接；这些网络条件需要在实际设备环境验证。
